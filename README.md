# Проект: приложение для банков

## Описание:

Проект bank-widget для разных функций для банков

## Установка:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/kopchik09/bank-widget/tree/main
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование:

1. файл masks.py шифрует номер счета или карты.
2. файл widget.py полноценно с маркой банковоской карты или счетом шифрует номер, а также определяет по полной дате точный месяц, число и год, и пишет их в удобной, привычной форме.
3. файл processing.py определяет работы по id и сортирует какие работы выполнены, а какие нет, также он может сортировать все работы по дате.
4. Модуль generators.py содержит функции-генераторы для обработки данных о транзакциях: filter_by_currency: фильтрация транзакций по валюте. transaction_descriptions: последовательный вывод описаний операций. card_number_generator: генерация номеров банковских карт в заданном диапазоне.
