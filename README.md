# Проект X

## Описание:

Проект bank-widget нужен для шифрования номера карточек и счетов

## Установка:
ы
1. Клонируйте репозиторий:
```
git clone https://github.com/kopchik09/bank-widget/tree/main
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. файл masks.py шифрует номер счета или карты
2. файл widget.py полноценно с маркой банковоской карты или счетом шифрует также номер, а также определяет по полной дате точный месяц, число и год, и пишет их в удобной, привычной форме
3. файл processing.py определяет работы по айди и сортирует какие работы выполнены, а какие нет, также он может сортировать все работы по дате.
